# Currency Tracker (Трекер валют)

Учебный проект на Python: получение курсов валют из API ЦБ РФ, сохранение истории и аналитика.

## Что делает
- Делает GET-запрос к API Центробанка (`cbr-xml-daily.ru`).
- Извлекает курсы Доллара (USD) и Евро (EUR) из вложенного JSON.
- Создает объекты класса `Currency` с валидацией данных.
- Сохраняет историю курсов в локальный файл `history.json`.
- Загружает историю из файла при запуске.
- Защищен от дублирования данных (один и тот же курс за одну дату не запишется дважды).
- Умеет находить максимальный курс валюты за всю историю.

## Использованные технологии
- **ООП**: классы `Currency` и `CurrencyTracker`, наследование не использовалось, но применены `@property`, магические методы (`__str__`, `__repr__`).
- **Работа с API**: библиотека `requests`, обработка ошибок сети, таймауты.
- **Работа с файлами**: `json` для сохранения состояния.
- **Обработка исключений**: `try/except` для сетевых ошибок и отсутствия файлов.
- **Виртуальное окружение**: `myenv`.

## Как запустить
1. Склонируйте репозиторий.
2. Создайте виртуальное окружение: `python -m venv myenv`.
3. Активируйте его: `myenv\Scripts\activate` (Windows).
4. Установите зависимости: `pip install -r requirements.txt`.
5. Запустите: `python main.py`.

## Файлы
- `tracker.py` — классы `Currency` и `CurrencyTracker`.
- `main.py` — демонстрация работы.
- `history.json` — создается автоматически (в `.gitignore`).
- `.gitignore` — исключает `myenv`, `__pycache__` и `history.json`.
